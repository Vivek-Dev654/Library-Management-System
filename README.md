# 📚 Library Management System

A simple Library Management System built using **HTML, CSS, and JavaScript**.

## ✨ Features

* 📚 Add new books
* 🔍 Search books
* 📖 Issue books
* 🔄 Return books
* 🗑️ Delete books
* 📊 Dashboard statistics
* 🌙 Dark/Light Mode
* 💾 Local Storage

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
